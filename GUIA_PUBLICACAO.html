Minha Escala · pronto para publicar

Do arquivo ZIP ao aplicativo instalado.

Você vai enviar os arquivos para o GitHub, ativar o Pages e abrir o endereço do aplicativo. Não precisa instalar ferramentas de programação.

1Extraia o pacote

Extraia o ZIP para uma pasta. Dentro dela, confira estes itens:

  • index.html, manifest.webmanifest e sw.js
  • Pastas assets e icons
  • Arquivo .nojekyll
O arquivo index.html precisa ficar na raiz do repositório, junto das pastas assets e icons. Envie os arquivos extraídos, não o ZIP.

2Crie o repositório

  1. Entre no GitHub e crie um novo repositório.
  2. Escolha um nome, como minha-escala.
  3. Escolha Public para usar Pages no plano pessoal gratuito.
  4. Abra Add file → Upload files.
  5. Arraste o conteúdo da pasta extraída, incluindo as duas pastas, e salve em Commit changes.

Envie somente este aplicativo. As planilhas da empresa serão anexadas dentro do aplicativo, no dispositivo de cada funcionário.

3Ative o GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save

Aguarde a publicação. O GitHub mostrará o endereço do site nessa mesma página.

O formato é https://SEU_USUARIO.github.io/minha-escala/. Use o endereço real informado pelo GitHub.

Se o arquivo .nojekyll não tiver sido enviado, crie-o no repositório com Add file → Create new file.

4Abra e confira sua escala

  1. Abra o endereço HTTPS publicado.
  2. Clique em Anexar planilha e escolha o Excel.
  3. Selecione seu nome e confira o calendário.
  4. Toque em um dia para ver horário, equipe e observações.
  5. Confira também os nomes tachados: eles aparecem como ausências e não somam horas de trabalho.

Android ou computador

Abra no Chrome ou Edge e toque em Instalar aplicativo. Se a janela não aparecer, procure a opção de instalação no menu do navegador.

iPhone ou iPad

Abra no Safari, toque em Compartilhar → Adicionar à Tela de Início e confirme. Se a opção aparecer, mantenha Abrir como App da Web ativada.

Confira o uso offline

Abra o aplicativo com internet e aguarde o carregamento completo. O rodapé informa quando ele estiver disponível offline. Depois, ative o modo avião e confira se a última escala continua disponível.

O nome e a escala ficam no navegador de cada dispositivo. Se mudar de aparelho, limpar os dados ou não encontrar a escala após instalar, anexe o Excel novamente.

A instalação e o modo offline precisam do endereço publicado. Abrir index.html diretamente na pasta do computador não ativa o PWA.

Se aparecer um erro

  • 404: confira se o index.html está na raiz e se Pages usa main e /(root).
  • Tela sem cores ou botões: confira se as pastas assets e icons foram enviadas com os nomes originais.
  • Instalação não aparece: use HTTPS e o menu de instalação do navegador.
  • Nova versão não aparece: nas próximas atualizações, altere VERSION em sw.js. O aplicativo avisa quando a atualização estiver pronta.

Mais detalhes estão no README.md do pacote.
